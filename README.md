# 🖥️ CubeBedwars — Native Desktop Edition

Native high-performance desktop application for **CubeBedwars** built with Electron.

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run in development mode
npm start

# 3. Build standalone installers (Windows .exe, macOS .dmg, Linux .AppImage)
npm run dist:win
npm run dist:mac
npm run dist:linux
```

## ✨ Desktop Features
- Borderless immersive 60fps WebGL voxel rendering with dedicated GPU acceleration
- `F11` instant fullscreen toggle
- Low input latency with direct native mouse & pointer lock capture
- Offline single-player mode with autonomous tactical AI bots
- Serverless WebRTC multiplayer support
